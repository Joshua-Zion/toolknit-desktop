# README visual assets

This directory contains the compact, public-facing visual assets used by the
repository README. Keep the filenames stable so README links do not need to
change when a screenshot is refreshed. When a screenshot is intentionally
version-labelled, update this file and the README links together.

| File | Purpose | Recommended export |
| --- | --- | --- |
| `hero-v2.webp` | Opening visual shown at the top of the repository | WebP, wide format |
| `web-version.png` | ToolKnit web version preview shown near the support section | PNG, 16:9, 1600 px wide or larger |
| `donation-support.webp` | Alipay and WeChat donation QR codes | WebP |
| `supporters-thanks.webp` | Thanks list for supporters | WebP |
| `categories` | Category screenshots used by the README gallery | PNG screenshots; see `categories/README.md` |
| `star-growth.svg` | Decorative Star growth chart; the live Star badge in README remains the source of truth | SVG |

Do not add raw screen recordings, design source files, private user files, or
unoptimized images here. Replace an existing image in place instead of adding
dated filenames.
