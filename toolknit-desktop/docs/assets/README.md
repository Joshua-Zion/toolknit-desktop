# Repository visual assets

Place repository-facing visual assets in this directory.

- `readme-hero.gif`: the full-width animated opening image shown at the top of `toolknit-desktop/README.md`.
- `readme-home.png`: the centered home screen screenshot shown later in `toolknit-desktop/README.md`.
- `donate-alipay.jpg` / `donate-wechat.png`: official donation QR images whose public record is maintained in `toolknit-desktop/docs/SUPPORT.md`.

Use optimized assets. Do not add source videos, raw design files, user screenshots containing private data, or files that are unnecessarily large for a GitHub README.
