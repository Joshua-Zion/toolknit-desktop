# ToolKnit 桌面端更新日志

> 与网页端完整更新历史保持同步：
> https://toolknit.com/changelog.html

## v2.1.0 / v2.1 (2026-08-25)

### 11 项新增桌面工具

- 图像工具新增“图像裁剪”和“智能颜色替换”：支持比例预设、构图辅助线、磁吸居中、原始分辨率导出，以及带连通区域保护、阈值和边缘柔化的颜色替换。
- 文本工具新增“Markdown 文档编辑器”：支持 GFM、Mermaid、KaTeX、标题大纲、本地草稿、图片资源管理，以及 Markdown 和自包含 HTML 导出。
- 创意工具新增“颜色空间对比”：支持 OKLCH、OKLab、D65 Lab/LCh、RGB、HSL、HSV 与近似 CMYK 实时联动，并检测 sRGB、Display P3、Adobe RGB 和 Rec.2020 色域。
- 核心颜色转换与输入交互方案由 Joshua-Zion 通过 [PR #23](https://github.com/ZihangDong/toolknit-desktop/pull/23) 贡献，并完成 ToolKnit 2.1 主题、懒加载、生命周期和轨道渲染性能适配。
- 新增“开发者工具”分类，提供 JSON 格式化、Base64 编解码、URL 编解码、UUID v4 批量生成、JWT 查看器和 Hash & Crypto 共 6 项本地工具。
- Hash & Crypto 覆盖摘要、文件 Hash、HMAC、AES、DES、3DES、SM4、RC4、ChaCha20、Trivium、RSA 与 SM2 等 17 类模块；旧算法明确标记为仅兼容用途。
- C 盘清理完成风险分级、只读扫描和确认流程，并正式纳入 2.1 的 60 项桌面工具目录。相对上一版 49 项目录，本次净增 11 个工具入口。

### 工作台与交互

- 新增图片和视频自定义壁纸，首页、分类页、工具页与收藏卡片统一为可读性更高的玻璃拟态视觉。
- 工具卡片加入克制的水膜波纹悬停反馈，并统一分类胶囊、输入框、下拉菜单、Toast、按钮与中英文错误提示。
- 支持作者改为独立页面并复用完整顶部导航；开发者手记支持随机轮播、进度、暂停和继续。
- 首页、设置和反馈流程完成自适应排版；功能建议直接打开 GitHub Issues，移除不再使用的抽屉表单。

### 新工具性能与生命周期

- Markdown、颜色替换、开发者工具和密码算法模块按需加载；关闭页面时终止 Worker、任务、监听器、计时器、Canvas 缓冲与 Blob URL。
- 智能颜色替换使用降采样 Worker 预览、过期任务淘汰和原始分辨率原生导出，连续调参不会让旧结果覆盖新结果。
- 文件 Hash 与认证文件加解密采用流式原生处理，支持进度、取消、临时文件清理和成功后的安全发布。
- AES 文件模式使用版本化 `.tkaes` 容器、Argon2id 密钥派生和 AES-256-GCM 分块认证；错误密码或损坏容器不会留下不完整输出。
- 设置页优先快速检测并复用电脑上已有的 FFmpeg 与 LibreOffice，仅在缺失时提示下载运行时。

### PDF 工作流加固

- PDF 编辑器补齐页面全选、反选、复制、插入空白页、可重复编辑文字、源页面旋转预览和安全的未保存修改确认。
- 完整原始顺序的编辑器导出保留表单和文档元数据；重排、跨文件合并等重建路径会清理失效 Widget。
- PDF 加密迁移到桌面端 qpdf AES-256，支持 Unicode 密码、权限设置和表单/元数据保留；错误密码、超长密码和不可用引擎均明确反馈。
- PDF 增强使用统一渲染预算、损坏校验、分块临时会话和排他原子发布，不会覆盖已有文件或留下半成品。
- PDF 压缩在没有实际体积收益时不生成误导性的“成功文件”，批量结果只统计真实保存项。

### 图像与安全

- 图像转换和压缩统一处理 EXIF 方向、透明图像 JPEG 白底合成，并允许坏文件逐项失败而不丢失同批成功输出。
- 图像批处理完成面板展示具体失败项；原生像素回归覆盖透明通道、方向、WebP 无损和损坏输入。
- Markdown 预览使用 DOMPurify 清理文档内容；Mermaid 输出为静态 SVG，自包含 HTML 导出无需联网即可查看。
- 密码、密钥、私钥、IV、原文和运算结果不会进入 localStorage、日志或持久历史；页面内历史仅存在于当前会话。
- RSA PKCS#1 v1.5 兼容模式迁移到 Windows CNG，移除存在已知时序风险的旧实现；Rust 依赖升级到已修复版本，并在 CI 与正式发布流程加入 RustSec 审计门禁。
- 修复自定义 AI 服务地址的私网 HTTP 授权边界，拒绝公网 HTTP、凭据 URL、代理和重定向跟随。
- 修复硬件检测中高位 GPU 显示值溢出导致的读取失败。

### 发布质量

- CLI 资源 staging 纳入 PDF 结构模块并加入发布包合同测试。
- 桌面端扩展为 12 个分类、60 项工具；桌面应用、Tauri、Rust crate 与 `@toolknit/cli` 版本统一升级为 `2.1.0`。
- 发布门禁覆盖 PDF、图像、Markdown、开发者与密码工具、AI、媒体、PPT、CLI/MCP 和原生 Rust 回归。

## v2.0.0 / v2.0 (2026-08-16)

### 全新桌面端与视觉系统

- 49 个工具全部迁移到统一的黑白极简 2.0 视觉与交互标准页：固定顶部导航、返回首页、设置与窗口控制保持一致。
- 首页、设置页、帮助中心、支持作者页整体重做；新增最近使用、我的收藏与统一工具导航。
- 窗口支持真实圆角、阴影与拉伸自适应；默认尺寸调整为 1400 × 900。

### 新增工具

- C盘清理：按低 / 中 / 高三档一键清理系统缓存与临时空间，含管理员检测、只读扫描、5 秒倒计时确认与永久删除提示。
- 小型 PDF 编辑器：页面预览、直接修改文字、插入文本 / 图像 / 形状、组件选择 / 拖动 / 缩放 / 旋转 / 删除、撤销与滚轮缩放。
- 屏幕取色：程序外实时放大镜取色，支持全局快捷键，取色时主窗口自动最小化。

### PPT 工具链

- PPT 转 PDF、PPT 转图像、PPT 图片素材提取、PPT 文本提取、PPT 压缩、AI 生成 PPT 大纲、AI 生成 PPT 草稿 / PPTX 全链路补齐。
- PPT 渲染运行时改为按需下载（官方源 / 国内镜像），不再塞进安装包。

### AI 能力

- AI 文档生成与编辑、AI 表格生成、AI 翻译、AI 润色、AI PPT 大纲与草稿，统一黑白极简排版与可编辑输出。

### CLI、MCP 与 Agent

- 发布 `@toolknit/cli` 2.0.0，覆盖 PDF / 图像 / 音视频 / 文本 / PPT / AI 文档 / AI 表格等命令与 MCP 工具。

### 设置与体验

- 新增界面音效（三套可切换）、屏幕取色快捷键、检查版本更新（GitHub Releases 比对并跳转下载）。
- 支持作者页与开发日志、程序声明与使用规范补齐。

### 质量与安全

- 硬件检测支持更多 Windows 系统；清理大文件、文本统计、音视频提取等边界场景修复与自适应优化。

## v1.2.8 / v1.2 (2026-08-04)

### 桌面端与本地工作流

- 首页重构为最近使用、推荐工具、我的收藏、支持作者与开源数据展示；保留动态背景和中英双语体验。
- 设置页支持统一输出根目录，并按工具二级分类保存；支持自定义图片或视频背景，失效时自动回退默认视觉背景。
- 所有会产出文件的桌面工作流使用统一完成弹窗、唯一命名和原子写入，避免覆盖原件或留下半成品。
- 窗口固定为 1160 x 780；关闭按钮默认隐藏到系统托盘，托盘菜单可显式退出程序。

### 工具能力

- PDF 合并、拆分、旋转、加密/解密、压缩和增强完成输入校验、选页、预览和输出安全收口。
- 音频转换、剪辑、提取和 BPM 分析，以及视频格式转换、高清单帧截取和最长 30 秒 GIF 截取完成本地处理契约。
- 新增长图拼接，支持图片与 PDF 页导入、横竖拼接、间距/背景/参考尺寸、取消、进度和输出预览。
- 音视频转文字使用可下载的本地 Whisper 模型，支持中文/英文转写、TXT/SRT/JSON 输出，以及可选 DeepSeek 二次润色。

### AI 文档与 AI 表格

- AI 文档输出可编辑工程、干净预览和编号图；桌面端与 IDE Agent 都可按稳定控件编号修改位置、尺寸、样式、对齐、层级、图像和表格。
- AI 表格输出 XLSX/CSV/PDF/PNG、可编辑工程和预览；支持稳定行列图表编号、试运行、修改、撤销、图表和公式注入防护。
- DeepSeek/OpenAI 兼容调用增加严格结构校验、有限重试、页数验证和输出原子发布。

### CLI、MCP 与依赖

- 发布独立 `@toolknit/cli`，支持 PDF、音频、视频、文本、颜色、长图拼接、离线转写、AI 文档与 AI 表格命令及 MCP 工具。
- 提供中英文 Agent 手册、自然语言提示词、结构化进度、退出码、JSON 输出和不污染 MCP stdio 的 ASCII 横幅。
- FFmpeg 与 Whisper 模型使用官方源/国内镜像按需下载；下载具备校验、断点续传和状态检查。

### 质量与安全

- 修复并验证文件锁定、输出碰撞、符号链接、损坏输入、取消、中途失败和自定义背景媒体 Range 请求等边界场景。
- 移除未使用的 `xlsx` 高危依赖，升级受影响的依赖树并将完整 npm 审计收敛到零漏洞。
- 发行前回归覆盖 PDF、AI 文档/表格、图像、音视频、长图拼接、CLI/MCP、依赖契约与 23 项 Rust 原生测试。

## 1.0测试版 / v1.0 Beta (2026-06-30)

ToolKnit 桌面客户端首个公开测试版正式上线。所有文件在本地处理，无需上传云端，随时随地离线可用。

### 核心亮点

- **桌面客户端首发**：Windows 原生 .exe 应用，安装即用，支持深色主题与 WebGL 动态背景，延续网页版一致的视觉体验。
- **中英双语界面**：一键切换 中文 / English，全部工具文案、提示与按钮均已完成本地化。
- **蜘蛛精灵加载动画**：页面切换与工具处理过程中加入专属蜘蛛吉祥物过渡动画，让等待不再枯燥。
- **统一安装器**：可视化安装向导，支持自定义安装路径、桌面快捷方式、开始菜单入口，以及语言偏好记忆。

### 已集成的工具套件

- **PDF 工具箱**：PDF 转图片、拆分、合并、压缩、旋转、加密/解密、格式转换、页码提取、水印处理等。
- **图片工具箱**：格式转换、批量转换、压缩、批量压缩、图片去水印、裁剪、拼图等。
- **音频工具箱**：格式转换、音频剪辑、音频提取、BPM 检测、声道处理等。
- **视频工具箱**：格式转换、视频截图、视频压缩等。
- **文本工具箱**：全角半角转换、文本反转、简繁转换、大小写转换、文本格式化等。
- **AI 创意助手**：AI 翻译、AI 润色、AI 文档生成、AI 角色扮演等。

### 使用体验

- **离线优先**：所有工具不依赖网络，本地运行，隐私文件无需上传。
- **拖拽处理**：PDF、图片、音频、视频等文件支持拖拽导入，操作直观。
- **批量处理**：图片、音频等工具支持批量导入与一键导出，提升工作效率。
- **导出路径记忆**：设置页可自定义默认保存位置，后续导出自动沿用。
- **侧边栏导航**：首页、PDF、图片、音频、视频、AI 等分类清晰，工具快速定位。
